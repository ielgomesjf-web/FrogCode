# 🐸 FrogCode

Uma linguagem de programação **em português** pra fazer jogos 3D e 2D no navegador, da **Frogbit Studio**.

**▶ Abrir:** https://ielgomesjf-web.github.io/FrogCode/

```
jogo: 3D
jogador: sapo
câmera em: atrás do jogador 5 metros
criar 10 moedas espalhadas
objetivo1: ir atrás das 10 moedas

quando pegar moeda:
  mensagem "Uma moeda!"
```

## O que tem

- **📝 Código**: editor tipo VS Code, com cores, sugestões e erros explicados em português
- **🎬 Cena**: monte o mapa arrastando as coisas, tipo Unity
- **🧱 Modelos**: monte personagens com peças (cubo, bola, cone...), tipo Blender
- **🎮 Jogo**: roda na hora; no celular aparece joystick
- **📖 Manual**: tudo explicado, com exemplos pra testar

**🤖 Aprendendo com uma IA (Claude, etc.)?** Ela não conhece o FrogCode. Cole o [GUIA-IA.md](GUIA-IA.md) na conversa antes de perguntar (ou use o botão *Copiar guia pra IA* no Manual).

Funciona no computador e no celular. Os jogos ficam salvos no próprio navegador (use ⬇ pra guardar um arquivo `.frog`).

Feito com [three.js](https://threejs.org).
